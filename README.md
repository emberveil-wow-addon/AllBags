# AllBags

Все сумки в одном окне для клиента Emberveil (WoW 1.12.1).

![version](https://img.shields.io/badge/version-1.2.0-blue) ![client](https://img.shields.io/badge/client-1.12.1-lightgrey)

Вместо пяти отдельных окон — одна сетка со всем содержимым рюкзака и сумок.

## Возможности

- **Одно окно** на все сумки, ширина сетки настраивается от 4 до 20 столбцов
- **Настраиваемый порядок сортировки**: шесть условий, которые расставляются по своему вкусу и включаются по отдельности
- **Избранное**: Alt+ЛКМ помечает вещь звёздочкой, помеченные всегда идут первыми
- **Свой порядок типов предметов** вместо алфавитного
- **Рамки качества**: необычное и выше подсвечивается цветом
- **Деление по сумкам** при выключенной сортировке: каждая сумка начинается с новой строки
- **Полное взаимодействие**: ЛКМ взять или положить, ПКМ использовать, надеть, продать или убрать в банк, Shift+ЛКМ ссылка в чат или деление стопки, подсказки при наведении
- **Деньги и свободное место** в нижней строке, стоимость содержимого — если установлен ItemLens
- **Хранилище**: сумки, банк, надетое и лоты аукциона всех персонажей аккаунта в отдельном окне

Сортировка **виртуальная**: предметы в сумках не перекладываются, меняется только порядок показа. Настоящее перекладывание потребовало бы десятков подряд идущих `PickupContainerItem` и рассыпалось бы на любой сетевой заминке.

## Как открывается

Аддон перехватывает штатные функции открытия сумок, поэтому работает любая клавиша, которая уже назначена на сумки, клик по кнопке сумки и автооткрытие у торговца. Своя команда — `/bags`.

## Сортировка

Порядок сортировки — это список из шести условий. Сравнение идёт сверху вниз и останавливается на первом различии: верхняя строка задаёт крупную группировку, нижние решают ничьи.

| Условие | Что делает |
|---|---|
| избранное | помеченные Alt+ЛКМ вещи идут первыми |
| по типу предмета | оружие, броня, расходуемые и так далее — в порядке, который задаётся отдельно |
| по качеству | от лучшего к худшему |
| по названию | по алфавиту |
| по размеру стопки | от полной к неполной |
| по сумке и ячейке | как лежит в сумках |

Каждое условие двигается стрелками `^` и `v` и включается квадратом слева. Пустые ячейки всегда уходят в конец.

**Порядок типов** настраивается отдельной кнопкой в окне настроек или командой `/bags types`. Список наполняется сам: класс предмета приходит от клиента локализованным, поэтому аддон записывает каждый встреченный класс и даёт расставить их стрелками. Класс, которого ещё нет в списке, уходит в конец.

## Избранное

**Alt+ЛКМ** по вещи ставит и снимает золотую метку в углу ячейки. Пометка хранится по названию предмета, так что держится и после того, как вещь переложили в другую сумку. Условие «избранное» по умолчанию стоит первым, так что помеченное всегда наверху.

## Управление

- **Правая кнопка по рамке окна** — меню; «Настройки…» на строке «По качеству» открывают окно с порядком сортировки
- **Левая кнопка** — перетаскивание, положение запоминается
- Меню и оба окна настроек перетаскиваются и закрываются по Esc

| Действие | Что происходит |
|---|---|
| ЛКМ | взять или положить предмет |
| ПКМ | использовать, надеть, продать, убрать в банк |
| Shift+ЛКМ | ссылка в открытую строку чата, иначе деление стопки |
| Alt+ЛКМ | пометить звёздочкой |

| Команда | Действие |
|---|---|
| `/bags` | Открыть или закрыть окно |
| `/bags config` | Окно настроек |
| `/bags types` | Порядок типов предметов |
| `/bags fav` | Показать список помеченных |
| `/bags fav clear` | Снять все пометки |
| `/bags menu` | Меню |
| `/bags sort` | Переключить сортировку |
| `/bags cols N` | Столбцов в ряду, 4–20 |
| `/bags border N` | Толщина окантовки окна, 2–24 |
| `/bags value` | Показывать стоимость содержимого |
| `/bags lang ru` \| `en` \| `auto` | Язык |
| `/bags off` \| `on` | Отключить или включить перехват сумок |
| `/bags reset` | Вернуть окна на место |
| `/bags vault` \| `/vault` | Окно хранилища: сумки, банк, надетое и аукцион альтов |
| `/bags vault probe` | Диагностика: что записано по каждому персонажу |
| `/bags font` | Диагностика: какой шрифт клиент поставил на цифры стопок |

## Размер цифр

Количество в стопке рисуется шрифтовыми объектами самого клиента — теми же, которыми штатные сумки рисуют свои цифры: белыми, с обводкой. Поэтому размер не свободное число, а шаг по списку: 12, 14, 16, 30. Этот клиент не умеет менять размер шрифта у FontString напрямую и не масштабирует текст вместе с фреймом, так что промежуточных размеров взять неоткуда.

## Хранилище: другие персонажи

Кнопка **«Альты»** в шапке окна (или `/bags vault`, или `/vault`) открывает второе окно со всем, что аддон запомнил по каждому персонажу аккаунта. Слева список персонажей с уровнем и классом, справа четыре вкладки.

| Вкладка | Что показывает | Когда запоминается |
|---|---|---|
| Сумки | рюкзак и четыре сумки | на ходу, пока играешь этим персонажем |
| Банк | панель банка и банковские сумки | когда открываешь банк у банкира |
| Надето | все 19 слотов экипировки | при входе и при смене вещей |
| Аукцион | свои лоты: выкуп, ставка, остаток времени | когда открываешь свои продажи у аукционера |

Переключатель **«Группировать»** сводит одинаковые вещи в одну ячейку с суммарным количеством — сумка читается как список того, что в ней есть, а не как карта того, где что лежит. Выключается одним кликом, тогда возвращается раскладка по ячейкам с пустыми местами.

В подвале — деньги по всему аккаунту. Кнопка **«Забыть»** убирает персонажа из хранилища, с Shift — всех, кроме текущего. Текущего персонажа забывать нельзя: его снимок и так свежий.

Данные хранятся в `AllBagsVault` — это аккаунтная таблица, одна на всех персонажей. Игра пишет сохранёнки при выходе, а не по `/reload`, поэтому новый персонаж появится в списке после того, как ты им зайдёшь и выйдешь из игры.

Количество в стопке для банковских ячеек этот сервер не отдаёт вообще — там, где включена группировка, в углу ячейки показано число стопок, а не предметов.

## Стоимость содержимого

Если установлен [ItemLens](https://github.com/vivk-17/ItemLens), в нижней строке показывается, сколько торговец даст за содержимое сумок, и, по желанию, за содержимое банка. Ничего из этого не обязательно: нет ItemLens — просто нет строки, без ошибок.

## Установка

Распакуйте папку `AllBags` в `Interface/AddOns/`. В папке два файла кода: `AllBags.lua` — окно сумок, `AllBagsVault.lua` — хранилище. Второй файл нужен потому, что клиент разрешает 200 локальных переменных на файл, и в первом место закончилось.

## Языки

Русский и английский, определяется по языку клиента. Переключается вручную через меню или `/bags lang`.
